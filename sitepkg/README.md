# ❤️ Наше путешествие — Абхазия

Романтический сайт для двоих: выбираем места, пишем пожелания и собираем общий маршрут.

## Что внутри

- красивые анимации;
- кнопка «Хочу сюда» с сердечками и конфетти;
- общий выбор мест между телефонами;
- общий чат пожеланий;
- режим организатора с PIN;
- превращение пожелания в пункт маршрута;
- реальные фотографии мест из Wikimedia Commons, ссылки на страницы файлов — внизу сайта;
- локальный SQLite для запуска на компьютере;
- PostgreSQL для онлайн-версии на Render.

## Самый простой путь к онлайн-ссылке

Проект подготовлен под Render Blueprint.

1. На GitHub создай новый репозиторий, например `abkhazia-love`.
2. Загрузите в него содержимое этой папки (не сам ZIP-файл).
3. В Render открой создание Blueprint и выбери этот GitHub-репозиторий.
4. Render прочитает `render.yaml`, создаст web-сервис и PostgreSQL.
5. На этапе создания задай свой `ADMIN_PIN` вместо стандартного 2468.
6. После первого успешного deploy Render выдаст публичный адрес `*.onrender.com`.

После этого один и тот же адрес можно отправить вам обоим: выбранные места и пожелания будут общими.

### Важно про бесплатный Render

У бесплатного web-сервиса Render есть автоматическое выключение после 15 минут без входящих запросов; при следующем открытии сервис запускается снова, поэтому первый заход после простоя может быть заметно дольше обычного.

Бесплатный PostgreSQL у Render предназначен для тестов/небольших проектов и по текущим условиям удаляется после 30 дней. Для одной поездки это может быть достаточно; для долгого хранения маршрута потребуется другое постоянное хранилище или платный вариант.

## Локальный запуск Windows

1. Установи Python 3.11+.
2. Распакуй проект.
3. Дважды нажми `start.bat`.
4. Открой `http://127.0.0.1:5000`.

Скрипт сам создаст `venv`, поставит зависимости и запустит Flask.

## PIN организатора

По умолчанию локально: `2468`.
Для онлайн-сайта задай собственный PIN в Render через переменную `ADMIN_PIN`.

## Фотографии

Фотографии мест выбраны с Wikimedia Commons и являются реальными фотографиями соответствующих локаций. В самом сайте есть блок с источниками и авторами. Перед дальнейшим публичным использованием фотографий сохраняй атрибуцию, указанную на соответствующей странице файла.
